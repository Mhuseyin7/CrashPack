# Privacy

CrashPack is local-only. It has no network upload command and does not send data to AI or cloud services. It collects only configured sources and stores only sanitized content in a bundle.

`STRICT` is the conservative default and enables email, IP, and user-path redaction. The redaction report counts categories but never stores the values redacted. No automated redaction can guarantee removal of all sensitive material; recipients should review the ZIP contents locally before external sharing.
